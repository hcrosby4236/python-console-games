# Python Console Games 🎮

A collection of interactive command-line games built with Python as a semester final project.

## 🎮 Games

### 🌲 Scary Forest

A branching text-based adventure where players make decisions that determine the outcome of the story.

Different choices lead to different paths, encounters, and endings.

### 🐈 Cat Simulator

A 24-hour cat simulation where players decide how their cat spends the day.

Players can:

- Sleep
- Eat and clean
- Explore
- Play with toys
- Cause chaos

Each action uses a different amount of time, and the game ends when the 24-hour day is over.

### ✂️ Rock, Paper, Scissors

A classic Rock, Paper, Scissors game where the player competes against a computer-controlled opponent.

The computer's choice is randomly generated using Python's `random` module.

## 🛠️ Built With

- Python
- Python `random` module
- Command-line interface
